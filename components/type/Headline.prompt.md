The serif display voice. Every headline is a short, finished sentence.

```jsx
<Headline size="l">Review<br />chapter 3</Headline>
<Headline size="m">Today branched.</Headline>
```

Write "One, one, two, three, five, eight." not "FIBONACCI GROWTH". Never all-caps, never a colon-and-subtitle construction, never a number as the headline unless it is a time.
